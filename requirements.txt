# Upper/lower bounds here are deliberate, not decoration - see the
# "dependency drift" troubleshooting entry in README.md before loosening
# any of these. Streamlit Community Cloud forces the Python version (no
# runtime.txt support) and had moved to Python 3.14 by 2026-07-31; Streamlit
# only gained real Python 3.14 support in 1.60.0 (a PEP 649 deferred-
# annotation-evaluation fix), so streamlit MUST be >=1.60 here or the app
# silently fails to route through its own st.navigation()/sidebar code on
# Cloud (no traceback - it just falls back to Streamlit's default flat page
# list and default centered layout, which is what made this so confusing
# to diagnose). Separately, pandas 3.0 changed Arrow/dtype handling strictly
# enough to crash a real page (Subscription Types, mixed int/str column -
# also fixed in code), so pandas stays <3.0. Verified 2026-07-31 that
# streamlit>=1.60,<1.61 + pandas<3.0 + pyarrow<25 resolves cleanly together
# (streamlit 1.60.0 / pandas 2.3.3 / pyarrow 24.0.0) - don't assume that
# stays true for future streamlit 1.6x releases without re-checking.
